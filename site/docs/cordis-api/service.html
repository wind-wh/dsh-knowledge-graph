Service

English | 中文

上下文服务的基类。以插件形式加载的子类会将自身注册为 ctx.<name>。

用于在 ctx 上公开具名 API 的服务基类。

子类在构造函数中调用 super(ctx, name)。服务会立即注册，并随所属 fiber 自动移除。
